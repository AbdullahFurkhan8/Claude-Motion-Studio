1. What these reels are

A poly-animated reel is a 45 to 80 second vertical video where two faceted 3D characters talk. There is no narrator. One is a tired human and the other is a calm bot, and the bot wins the argument. The look is cheap to make and easy to repeat, so your audience recognises your characters and the only thing that changes is the idea.

2. Write a script that holds attention

Rules for every format

  • Use 17 to 33 lines of mostly 2 to 6 words, with a cut every 2 to 3 seconds.
  • State the problem in the first line, inside 3 seconds.
  • Use exact numbers: 38,412 is funnier and more believable than 40,000.
  • Pick an embarrassment your audience privately shares.
  • Let the human overreact and the bot answer in 1 to 4 words.
  • End on a callback, never a summary.
  • Write original lines. Study structure, not other creators' jokes.

Warm Explainer template

  1. Hook: the human blurts a big number or painful result.
  2. The bot rejects the obvious wish.
  3. 3 to 5 concrete steps, each shown on a screen panel.
  4. A joke objection every two steps.
  5. A payoff notification with a specific result.
  6. One dry last line, then an end card with a comment keyword.

Dark Sitcom template

  1. A tiny, reasonable request.
  2. The bot says yes and does far too much, with the damage shown as a number.
  3. 3 to 5 rungs, each with a straight-faced reason.
  4. Tone climbs from confused to bargaining to shouting.
  5. A reversal: the system turns on the human.
  6. A short final reaction. No end card, so it loops.

Night Talk template

  1. A quiet confession.
  2. Ping-pong lines, many of them one word.
  3. One real feeling, said plainly once.
  4. The bot lands a short true line.
  5. A soft callback or a loop back to the start.

3. Generate the voices

Use Gemini text-to-speech. It has a free way to try it in Google AI Studio, and an API for automation. Check current pricing and limits on Google's site, since they change. The cheaper model is gemini-3.8-flash-lite-tts.

Without code

  1. Open aistudio.google.com and choose the speech generation mode.
  2. Choose multi-speaker and give each speaker a prebuilt voice.
  3. Add a style line for each speaker.
  4. Paste the whole conversation at once, so it flows as one talk.
  5. Download the audio.

Emotion tags

Put tags in angle brackets inside the text. The voice acts them and does not read them.

<sad> One. <short pause> It said unsubscribe.
<deadpan> I can tell.
<laughs> Oh no. <gentle> Show me the email.

Useful tags: <happy> <excited> <sad> <angry> <frustrated> <shocked> <tired> <sarcastic> <deadpan> <teasing> <whispers> <laughs> <sighs> <short pause> <long pause>. Change the emotion between lines and put a pause right before a punchline.

Keep the same two voices forever. A recognisable voice builds an audience as much as the characters do.

4. Path A: use the skill, A to Z

This section takes you from an empty computer to a finished reel. You do not need to know how to code. Claude Code runs the commands, and you make the creative decisions.

Part 1: Install everything (once, about 30 minutes)

  1. Install Claude Code by following Anthropic's official instructions, then sign in.
  2. Install Node.js version 18 or newer from nodejs.org.
  3. Install Python 3.10 or newer from python.org. On Windows, tick "Add Python to PATH".
  4. Install ffmpeg from ffmpeg.org and make sure it is on your PATH.
  5. Get a Gemini API key at aistudio.google.com. Treat it like a password.
  6. Save the key as an environment variable named GEMINI_API_KEY, then close and reopen your terminal.
Windows (PowerShell):  setx GEMINI_API_KEY "your-key"
Mac (add to ~/.zshrc):  export GEMINI_API_KEY="your-key"

Check that the tools work. Each of these should print a version number:

node -v
python --version
ffmpeg -version

Part 2: Add the skill (once)

  1. Unzip the package, or clone it if you received repository access.
  2. Copy the poly-animated-reels folder into your project's .claude/skills/ folder. To use it in every project, put it in .claude/skills/ inside your home folder instead.
  3. Open a terminal in your project and run claude.
  4. Type /poly-animated-reels. If it appears, the skill is installed. If not, restart Claude Code.

Then send this once:

Set up poly-animated-reels for all three brands and tell me if anything is missing.

Claude installs the packages each brand needs. Approve its commands when asked. If the skill's optional sound-effects folder is missing, sound effects are skipped. Tell Claude where your own folder is and it can pass that location to the mix step.

Part 3: Make it yours (once)

  1. Choose one brand to start. Post one format long enough for people to recognise it.
  2. Pick your bot's name, then ask: Set the bot's script name to Pixel in dark-sitcom.
  3. Keep the default voices or change them now. After this, never change them.

Start with a prompt like this:

Four ways to start

The skill writes the script and handles every later step. It pauses twice: once for you to approve the script, and once for the voice and preview.

From a topic:     Make a poly-animated reel about why most cold emails fail.
Explainer:        Make an explainer reel on how noise cancelling really works.
Your script:      Turn this script into a reel: <paste it>
From a reference: Use reference.mp4. Copy its structure, not its words,
                  and write a new script about pricing for freelancers.
No stopping:      Do everything without stopping.

With a reference, the skill transcribes the video, studies its frames and pace, then writes a new script on your topic with the same structure. It does not copy the words or jokes.

Part 5: Ask for changes in plain words

Regenerate only the voices, keeping the same script.

Add a calendar panel on the line about eight weeks.
Make a Hindi version with Hinglish captions.

How to get the best results

  • Give specifics. "Freelancers chasing a late invoice" beats "money tips". Include a real detail from your life or niche.
  • Always approve the script first. It costs nothing to change. Voices and renders take time and may cost API credits.
  • Read it aloud. Cut any line you would not say to a friend.
  • Tune the voice with tags, not new voices. Vary the emotion and put a pause before each punchline.
  • Use panels with purpose. Show a number, result or joke. Night Talk should use one at most.
  • Trust the auto-director first. Override a shot only for a specific joke.
  • Check the first 3 seconds and last frame. They decide whether people stay and rewatch.
  • Keep the characters the same. Change the idea, location and lighting, not the cast.
  • Verify facts in any how-to. People will try what you teach.
  • Post a series. Make several reels on the same theme, then repeat what your comments and saves reward.
A simple weekly routine: write three scripts on Monday, approve the best two, render them on Tuesday, and post them across the week.

5. Path B: without the skill

This route uses free tools and your own hands. Expect a day for the first reel, then about two to three hours each once your scene file exists.

  1. Install Blender, which is free, from blender.org.
  2. Build the human. Start with an icosphere head at subdivision 1. Move a few vertices by hand, then set shading to Flat. Make the torso, arms and legs from tapered cubes. Add a small box mouth and sphere eyes.
  3. Build the bot. For a block bot, use one cube, four thin leg cubes and two black rectangles for eyes. For an orb bot, use a subdivided icosphere with a dark circle for a visor.
  4. Rig simply. Parent parts to empties at the neck, shoulders, elbows and hips. You only need a head turn, a body bob and a few arm poses.
  5. Build one set. A wall, a floor, a window with a gradient, and three or four props are enough.
  6. Add lighting using the recipe in section 6.
  7. Make a mouth loop. Keyframe three mouth sizes, then use them where the character speaks by following the audio waveform in the timeline.
  8. Set up cameras. Make one wide shot and one close-up per character at 1080×1920. Cut to whoever is speaking.
  9. Render with Eevee to stay fast.
  10. Edit in CapCut or DaVinci Resolve. Add the voice, auto-captions and very few sound effects. Put UI screens on top as images.
Save your characters and set in one Blender file. Every later reel reuses it, and only the audio, mouth timing and camera cuts change.

Change the location or light colour in every video so your feed stays fresh while the characters stay the same.

7. Publish checklist

  • The first line lands within 3 seconds.
  • Captions never cover a face or get cut off.
  • Audio sits near -14 LUFS.
  • No repeating pops or typing sounds.
  • The final frame loops or asks one clear question.
  • Any stated fact or method is accurate.
  • Characters and names are yours, with no real brand implied as your sponsor.

8. Troubleshooting

ProblemFix
Voice sounds flatAdd more varied tags and generate again.
A tag is spoken aloudGenerate again or shorten the line.

Faces are too brightLower the side light.

Missing API keySet GEMINI_API_KEY and reopen the terminal.
